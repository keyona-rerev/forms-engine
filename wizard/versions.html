Version history

This page lists what changed in each version and what to do to upgrade. New clients do not need it. Their copy is already current.

v1.0.2 Current

What changed: If Google Drive refuses a file (for example, your Drive storage is full), the form now says so in plain words. Before, it only said "Upload failed".

To upgrade: Replace Code.gs and Responses.gs with the new files from the repo (gas folder). Replace form-template.html content in your form page. Click Deploy, then New deployment, then Web app. Copy the new web app URL into your form page.

v1.0.1

What changed: Answers that start with = + - or @ are now saved as plain text. Before, an answer like =SUM(1,2) turned into a formula in your Sheet.

To upgrade: Open your Apps Script project. Replace the code in Responses.gs and Code.gs with the new files from the repo (gas folder). Then click Deploy, then New deployment, then Web app. Copy the new web app URL into your form page. Each new deployment makes a new URL.

v1.0.0

What changed: First release. Many forms from one Sheet. 24 question types. Logic jumps. Partial saves. File and signature uploads. Draft preview.

To upgrade: Nothing to do. This is the first version.

How upgrades work in future versions

Each entry will say what changed and give the exact steps: which script files to replace, and whether to deploy again. A new deployment makes a new web app URL, so each upgrade note will tell you to paste the new URL into your form page.
